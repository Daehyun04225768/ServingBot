# UI 폰트 크기 가이드

### 💻 PC 해상도별 권장 폰트 사이즈 (Pixel 기준)

| 구분 | 기본형 (FHD / 1920x1080 이하) | 대화면·고해상도 (4K / 2560x1440 이상) | 설명 |
| :--- | :--- | :--- | :--- |
| **대형 제목 (H1)** | 32px ~ 40px | 48px ~ 64px | 메인 배너, 랜딩 페이지 타이틀 |
| **중형 제목 (H2~H3)** | 20px ~ 28px | 28px ~ 36px | 대시보드 타이틀, 섹션 제목 |
| **소제목 (H4 / Subtitle)** | 16px ~ 18px | 18px ~ 22px | 리스트 제목, 카드 UI 타이틀 |
| **본문 (Body)** | **14px ~ 15px** | **16px ~ 17px** | 블로그글, 상세 안내문, 시스템 텍스트 |
| **UI 밀도 높은 본문** | 13px ~ 14px | 14px ~ 15px | 관리자 페이지, ERP, 데이터 테이블 |
| **캡션 / 부가 정보** | 11px ~ 12px | 12px ~ 13px | 힌트 텍스트, 푸터(Footer), 저작권 표기 |
